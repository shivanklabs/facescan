# backend/
FastAPI modular monolith. One codebase, two processes:
- `api`: `uvicorn app.main:create_app --factory`
- `worker`: `python -m app.worker` (claims jobs from the Postgres `jobs` table with
  `SELECT ... FOR UPDATE SKIP LOCKED`; retries with backoff; failed after the last attempt)

Must not: call paid services, import vendor SDKs outside `app/adapters/`, store selfies, log
biometrics or personal data. See security invariants in `/CLAUDE.md`.

## Database
`uv run tasks db-init` (once, as the PostgreSQL superuser), then `uv run tasks db-migrate`.
Every transaction sets its RLS scope (`app/db/event_scope.py`); see `database/schema.md`.

## TEMPORARY dev-only API (until login is built)
A single admin bearer token from `FACESCAN_DEV_ADMIN_TOKEN` (generated by `uv run tasks
setup`), accepted **only when `FACESCAN_ENV=dev`**. The API refuses to start if the token is set
in any other environment. Remove these routes when passkey/email login lands.

| Method and path | What it does |
|---|---|
| `POST /events` `{"name", "country"}` | create an event and its wrapped data key |
| `GET /events` | list events (metadata only) |
| `GET /events/{id}` | status and counts |
| `POST /events/{id}/photos` (multipart `files`, optional `collection_id`) | validate (content type, size, pixels) and store in quarantine |
| `POST /events/{id}/collections/{cid}/approve` | move out of quarantine, queue `index_event` |
| `POST /events/{id}/match` (raw body, `Content-Type: image/jpeg`) | one-face selfie, photo ids per band |

The worker's `index_event` job stores faces, clusters, prototypes and calibration encrypted
under the event key and writes EXIF-free web copies. Every action writes an audit row.

PowerShell example (replace TOKEN with the value from .env):
```
$h = @{ Authorization = "Bearer TOKEN" }
$e = Invoke-RestMethod -Method Post http://127.0.0.1:8000/events -Headers $h -ContentType application/json -Body '{"name":"Test","country":"IN"}'
curl.exe -H "Authorization: Bearer TOKEN" -F "files=@photo1.jpg" -F "files=@photo2.jpg" "http://127.0.0.1:8000/events/$($e.event_id)/photos"
curl.exe -H "Authorization: Bearer TOKEN" -H "Content-Type: image/jpeg" --data-binary "@selfie.jpg" "http://127.0.0.1:8000/events/$($e.event_id)/match"
```
