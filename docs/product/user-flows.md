# User flows (draft)

1. Guest: open event link -> log in (passkey / magic link) -> consent -> selfie + liveness ->
   gallery of released photos -> claim a photo -> privacy settings (withdraw, delete).
2. Photographer: upload photos -> watch processing status.
3. Organiser: set up event -> approve collection -> review claim queue.
4. Admin: platform dashboard (no face search).
